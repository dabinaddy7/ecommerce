## 3. 새로 배운 핵심 파이썬 메서드 & 함수

### 📋 데이터 요약 및 집계
* **`pd.to_datetime(df['컬럼'], format=...)`**
  * 문자열로 된 날짜 데이터를 파이썬이 인식할 수 있는 날짜/시간(datetime) 타입으로 변환함.
* **`dt.year` / `dt.month` / `str.zfill(2)`**
  * 날짜 데이터에서 연, 월을 문자로 추출하고 `zfill(2)`를 통해 `1월`을 `01월`로 만들어 정렬 순서가 꼬이지 않게 방어함.
* **`nunique()`**
  * `count()`와 달리 중복을 제거한 **고유값의 개수**만 산출함. 한 영수증에 여러 상품 줄이 섞여 있는 쇼핑몰 데이터에서 '진짜 주문 건수'를 세어주는 일등 공신.
* **🌟 `agg({'컬럼': '함수'})`**
  * 그룹화(`groupby`) 후 여러 컬럼에 각각 서로 다른 집계(예: 한쪽은 `sum`, 다른 쪽은 `nunique`)를 한 번에 처리하는 뷔페식 요리 메서드. 지표들을 하나의 테이블로 깔끔하게 묶어줌.

### 📈 데이터 시각화 (Seaborn)
* **`sns.lineplot(data=..., x=..., y=...)`**
  * 시간에 따른 데이터의 연속적인 흐름(트렌드)을 파악할 때 사용하는 선 그래프.
* **`plt.xticks(rotation=45)`**
  * x축 글자(연월)가 길어서 서로 겹칠 때, 글자를 45도 기울여서 가독성을 높여주는 시각화 팁.

## 4. 💡 가장 중요했던 데이터 분석 개념 피드백

### ❓ "왜 `data=df`로 그래프를 그리지 않고, `data=monthly_sales_clean`으로 그리나요?"
* **행의 개수(데이터의 스케일)가 다름**: 원본 `df`는 **54만 줄**짜리 거대한 창고이고, `monthly_sales_clean`은 판다스로 요약해 둔 딱 **13줄**짜리 요리 접시임.
* **시각화 목적의 차이**: 우리가 원하는 것은 월별로 점을 딱 13개만 찍어서 선으로 연결하는 트렌드 플롯임. 54만 줄짜리 원본을 그대로 밀어 넣으면 컴퓨터는 월별 총합이 아니라 그 달에 포함된 모든 개별 상품의 매출 평균과 오차 범위를 계산하느라 그래프가 완전히 꼬이게 됨.
* **결론**: 트렌드 선 그래프를 그릴 때는 **"판다스로 먼저 엑기스(집계 데이터)를 완벽하게 짜낸 뒤, 그 요약된 표를 Seaborn에 던져주는 것"**이 정석임.

## 5. 최종 완성 통합 코드
```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# 1. 데이터 로드
df = pd.read_csv("data.csv", encoding="ISO-8859-1")

# 2. 전처리
df['InvoiceDate'] = pd.to_datetime(df['InvoiceDate'], format='%m/%d/%Y %H:%M')  
df['InvoYearMonth'] = df['InvoiceDate'].dt.year.astype(str) + "-" + df['InvoiceDate'].dt.month.astype(str).str.zfill(2)
df['TotalAmount'] = df['Quantity'] * df['UnitPrice']

# 3. agg를 활용한 월별 지표 집계 통합
monthly_aov = df.groupby('InvoYearMonth').agg({'TotalAmount':'sum', 'InvoiceNo':'nunique'}).reset_index()
monthly_aov['AverageOrderValue'] = monthly_aov['TotalAmount'] / monthly_aov['InvoiceNo']

# 4. 객단가(AOV) 시각화
sns.lineplot(data=monthly_aov, x='InvoYearMonth', y='AverageOrderValue', marker='o', color='r')
plt.title('Monthly Average Order Value (AOV) Trajectory')   
plt.xticks(rotation=45)
plt.grid(True)
plt.show()
